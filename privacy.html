Dial Drive プライバシーポリシー

制定日：2026年10月16日

1. このアプリについて

Dial Drive（以下「本アプリ」）は、開発者本人が自分の車で使うために作った個人用アプリです。一般には配布していません。

2. 取得する情報と使い方

本アプリは、利用者が許可した場合に限り、Google の OAuth を通じて YouTube Data API（スコープ：https://www.googleapis.com/auth/youtube）にアクセスします。使う目的は次の 1 つだけです。

  • 利用者本人の YouTube アカウントに非公開プレイリスト「Dial Drive オフライン」を作成し、本アプリでよく再生した曲をそのプレイリストに追加・削除すること

このほかの YouTube のデータ（視聴履歴、コメント、チャンネル情報など）を読み取ったり変更したりすることはありません。

3. 情報の保存場所

アクセストークン、再生回数の記録、設定などは、利用者の端末の中にだけ保存されます。開発者のサーバーや第三者に送信することはありません。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセスの取り消し

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から、いつでも本アプリのアクセスを取り消せます。取り消すと、本アプリはプレイリストを変更できなくなります。
